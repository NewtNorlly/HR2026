建议：给年刊每章补一张「材料去哪找」小索引 #1

梅帅 2026-11-17 已处理

可以在章末放一张很短的资料索引，每条只写资料名、它能回答的问题和具体出处。例如，招聘章把岗位说明原文和结构化面试指引并排，让读者一眼知道哪些是原始材料、哪些是作者分析。先挑一章试做五条，看看能不能更快定位证据，再决定是否推广。
